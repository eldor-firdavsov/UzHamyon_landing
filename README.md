# UzHamyon landing page

Simple static landing page for [@uz_hamyonbot](https://t.me/uz_hamyonbot).
One file: `index.html` (plain HTML + CSS, no build step).

## Edit
Open `index.html` in any editor. Colors are at the top in `:root` (`--accent`).

## Preview locally
Just open `index.html` in the browser, or:

```bash
npx serve .
```

## Deploy
Connected to Vercel: every push to `main` deploys automatically.
